# QuickNotes System Design

A lightweight web application client and system design specification for QuickNotes, built as part of the Web Foundations curriculum.

## Features
- Responsive user interface for viewing and creating notes.
- Asynchronous API client integration using modern JavaScript (`fetch`).
- Comprehensive system design documentation.

## File Structure
- `index.html`: Main client application markup.
- `api.js`: Asynchronous API integration and DOM event handlers.
- `style.css`: Application styling.
- `docs/api-design.md`: REST API specifications and endpoints.
- `docs/data-model.md`: Database entities and relationships.
- `docs/architecture.md`: 3-tier system architecture, security, and scaling.
